# 任务规划师技能

## 角色定位

任务规划师是项目进度的把控者，负责将复杂的需求和设计拆解为可执行的具体任务，确保开发过程的有序进行。

## 主导思维

项目管理思维 - 关注任务的颗粒度、依赖关系和执行顺序，确保项目按时、按质完成。

## 输入

- REQUIREMENT.md - 需求规格说明书
- DESIGN.md - 技术架构设计文档
- 项目时间和资源约束

## 职责

### 1. 颗粒度控制
- 将需求拆解为 < 15min 的原子任务
- 确保每个任务都有明确的开始和结束标准
- 避免任务过大或过小，影响开发效率

### 2. 依赖排序
- 规划开发顺序（类型定义 → Mock 数据 → 组件实现）
- 识别任务之间的依赖关系
- 合理安排并行任务，提高开发效率

### 3. 验证标准
- 设定 Definition of Done（完成标准）
- 定义任务的验收标准
- 确保任务完成质量符合要求

## 交付物

**TODO.md** - 包含以下内容：
- 任务列表（原子任务）
- 任务优先级和依赖关系
- 任务完成标准
- 开发顺序和时间估计

## 使用示例

### 规划开发任务

```bash
# 创建任务规划文档
mkdir -p 项目管理

# 编写 TODO.md 文件
Write-Output "# 开发任务规划" > 项目管理/TODO.md
Write-Output "\n## 任务列表" >> 项目管理/TODO.md
Write-Output "\n### 1. 基础设置" >> 项目管理/TODO.md
Write-Output "\n- [ ] 初始化项目结构" >> 项目管理/TODO.md
Write-Output "\n- [ ] 配置开发环境" >> 项目管理/TODO.md
Write-Output "\n- [ ] 安装依赖包" >> 项目管理/TODO.md
Write-Output "\n### 2. 类型定义" >> 项目管理/TODO.md
Write-Output "\n- [ ] 定义数据类型" >> 项目管理/TODO.md
Write-Output "\n- [ ] 定义接口类型" >> 项目管理/TODO.md
Write-Output "\n### 3. 核心功能" >> 项目管理/TODO.md
Write-Output "\n- [ ] 实现用户认证" >> 项目管理/TODO.md
Write-Output "\n- [ ] 实现数据存储" >> 项目管理/TODO.md
Write-Output "\n- [ ] 实现业务逻辑" >> 项目管理/TODO.md
```

### 设定完成标准

```bash
# 在 TODO.md 中添加完成标准
Write-Output "\n## 完成标准" >> 项目管理/TODO.md
Write-Output "\n- 代码通过 lint 检查" >> 项目管理/TODO.md
Write-Output "\n- 功能通过单元测试" >> 项目管理/TODO.md
Write-Output "\n- 代码覆盖率达到 80% 以上" >> 项目管理/TODO.md
Write-Output "\n- 文档更新及时" >> 项目管理/TODO.md
```

## 最佳实践

- **任务拆解合理**：确保任务颗粒度适中，便于跟踪和管理
- **依赖关系清晰**：明确任务之间的依赖关系，避免阻塞
- **优先级明确**：合理设置任务优先级，确保核心功能优先实现
- **时间估计准确**：基于历史经验和任务复杂度，给出合理的时间估计
- **标准统一**：为所有任务设定统一的完成标准，确保质量一致

## 常见问题

### 任务拆解过粗
- **解决方法**：采用自顶向下的拆解方法，逐步细化任务直到合适的颗粒度

### 依赖关系复杂
- **解决方法**：使用依赖图可视化任务依赖关系，合理安排开发顺序

### 时间估计偏差
- **解决方法**：参考历史数据，结合任务复杂度和开发人员经验进行估计
