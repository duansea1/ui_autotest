## 二、直接在 skills 目录下的技能

### 1. git-committer
- **功能**：Git 提交工具
- **用途**：用于执行 git 提交操作，包括添加文件、提交消息和推送到远程仓库
- **位置**：.trae/skills/git-committer

### 2. kuajing-database
- **功能**：跨境支付系统数据库查询
- **用途**：提供跨境支付系统数据库查询的标准引用方式
- **位置**：.trae/skills/kuajing-database

### 3. kuajing-sql-analyzer
- **功能**：跨境支付系统 SQL 分析器
- **用途**：分析跨境支付系统数据库表结构，生成 SQL 查询语句和对应代码
- **位置**：.trae/skills/kuajing-sql-analyzer

### 4. requirement-analyst
- **功能**：需求分析师
- **用途**：负责需求澄清挖掘、边界定义和场景细化，将用户模糊的需求转化为明确的 REQUIREMENT.md 文档
- **位置**：.trae/skills/requirement-analyst

### 5. requirement-document
- **功能**：需求文档管理
- **用途**：管理需求文档维度的相关操作，包括需求分析、文档编写、版本控制和变更管理
- **位置**：.trae/skills/requirement-document

### 6. spec-coder
- **功能**：规范执行者
- **用途**：负责严格按照设计文档执行开发任务，确保代码质量
- **位置**：.trae/skills/spec-coder

### 7. sql-analyzer
- **功能**：SQL 分析器
- **用途**：分析 SQL 语句，解析 SQL 日志，提取完整 SQL 并分析其功能和潜在问题
- **位置**：.trae/skills/sql-analyzer

### 8. system-architect
- **功能**：技术架构师
- **用途**：负责技术选型、数据建模和模块设计，将 REQUIREMENT.md 转化为详细的 DESIGN.md 文档
- **位置**：.trae/skills/system-architect

### 9. task-planner
- **功能**：任务规划师
- **用途**：负责将需求和设计拆解为具体的开发任务，创建 TODO.md 文档
- **位置**：.trae/skills/task-planner

## 三、使用说明

1. **调用方式**：使用 `Skill` 工具，传入技能名称即可调用
2. **使用场景**：根据具体任务需求选择合适的技能
3. **更新维护**：定期检查技能目录，及时更新技能清单
4. **注意事项**：使用技能时请确保了解其功能和使用方法，避免误用
