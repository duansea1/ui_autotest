# Git 提交技能

## 功能

此技能用于执行 git 提交操作，包括：
- 添加更改的文件到暂存区
- 创建提交消息
- 推送到远程仓库

## 使用场景

当用户需要：
- 提交代码更改
- 推送本地更改到远程仓库
- 执行完整的 git 提交流程

## 使用示例

### 基本提交

```bash
# 添加所有更改的文件
git add .

# 提交更改
git commit -m "提交消息"

# 推送到远程仓库
git push
```

### 提交特定文件

```bash
# 添加特定文件
git add 文件路径

# 提交更改
git commit -m "提交消息"

# 推送到远程仓库
git push
```

### 查看状态

在提交前，可以查看当前 git 状态：

```bash
git status
```

## 注意事项

- 确保在正确的 git 仓库目录中执行命令
- 提供有意义的提交消息，描述更改的内容
- 对于大型更改，考虑分多次提交
- 定期推送更改到远程仓库以备份代码

## 常见问题

### 提交失败
- 检查是否有未解决的冲突
- 确保有正确的 git 权限
- 验证远程仓库连接

### 推送失败
- 检查网络连接
- 确保本地分支与远程分支同步
- 验证推送权限
