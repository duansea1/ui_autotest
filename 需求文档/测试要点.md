# 外汇交易中心仓位管理测试要点

## 1. 功能测试要点

### 1.1 总持仓敞口统计测试

#### 1.1.1 币种对维度统计测试
- [ ] 验证系统是否按币种对维度正确统计敞口
- [ ] 验证所有币种对的数据是否完整显示
- [ ] 验证新增币种对后是否自动纳入统计

#### 1.1.2 敞口计算规则测试
- [ ] **卖出币种为USD的情况**：验证当卖出币种为USD时，是否正确取卖出金额作为敞口
- [ ] **买入币种为USD的情况**：验证当买入币种为USD时，是否正确取买入金额作为敞口
- [ ] **都没有USD的情况**：验证当买入和卖出币种都不是USD时，是否正确取卖出金额折合USD作为敞口
- [ ] **轧差计算测试**：验证sell和buy金额轧差计算是否正确
  - 测试场景1：卖出金额 > 买入金额
  - 测试场景2：买入金额 > 卖出金额
  - 测试场景3：卖出金额 = 买入金额（敞口应为0）

#### 1.1.3 USD折合计算测试
- [ ] 验证非USD币种的折合计算是否准确
- [ ] 验证汇率变动时折合计算是否实时更新
- [ ] 验证异常汇率情况（如汇率为0、负数等）的处理

### 1.2 仓位分布分析测试

#### 1.2.1 排序功能测试
- [ ] 验证币种对是否按持仓敞口(折合USD)降序排列
- [ ] 验证排序是否实时更新
- [ ] 验证多个币种对敞口相同时的排序逻辑

#### 1.2.2 数据展示测试
- [ ] 验证敞口(折合USD)是否正确显示
- [ ] 验证占总持仓比例是否正确计算和显示
- [ ] 验证占比计算的精确性（总和是否为100%）

#### 1.2.3 无敞口币种对处理测试
- [ ] 验证无敞口的币种对是否不参与仓位分布分析
- [ ] 验证所有币种对敞口为0时的页面显示

### 1.3 单一货币对最大敞口限制测试

#### 1.3.1 设置功能测试
- [ ] 验证是否支持设置单一货币对最大敞口限制
- [ ] 验证设置界面是否友好易用
- [ ] 验证设置值的有效性校验（如非负数、合理范围等）

#### 1.3.2 限制生效测试
- [ ] 验证当敞口未超过限制时，系统正常运行
- [ ] 验证当敞口超过限制时，系统是否提供告警
- [ ] 验证当敞口超过限制时，系统是否限制交易
- [ ] 验证告警信息是否清晰明确

#### 1.3.3 限制修改测试
- [ ] 验证修改最大敞口限制后是否立即生效
- [ ] 验证多次修改限制的情况

### 1.4 菜单位置测试
- [ ] 验证菜单位置是否正确：汇率管理->交易中心->仓位管理
- [ ] 验证导航路径是否可正常访问
- [ ] 验证权限不足时是否无法访问该菜单
