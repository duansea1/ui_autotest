# 外汇交易中心仓位管理需求规格说明书

## 1. 需求背景

外汇交易中心需要实现仓位管理功能，以便：
- 实时监控总持仓敞口情况
- 分析仓位分布，识别风险集中点
- 控制单一货币对的最大敞口，防范风险

## 2. 功能需求

### 2.1 总持仓敞口统计
- 按币种对维度进行统计
- 单一币种对敞口计算规则：
  - sell和buy进行轧差后的卖出/买入金额
  - 卖出币种为USD则取卖出金额
  - 买入币种为USD则取买入金额
  - 都没有则取卖出金额折合USD
- 敞口统计全部统一以折合USD进行展示

### 2.2 仓位分布分析
- 将存在敞口的币种对按计算出的持仓敞口(折合USD)按降序进行排列
- 展示敞口(折合USD)以及占总持仓比例

### 2.3 单一货币对最大敞口限制
- 支持设置单一货币对最大敞口限制(折合USD)
- 当敞口超过限制时，系统应提供告警或限制交易功能

### 2.4 菜单位置
- 菜单位置：汇率管理->交易中心->仓位管理

## 3. 非功能需求

### 3.1 性能需求
- 数据刷新频率：实时或近实时（不超过5秒）
- 页面响应时间：不超过2秒

### 3.2 安全需求
- 权限控制：仅授权人员可访问仓位管理功能
- 数据加密：敏感交易数据传输加密

### 3.3 可靠性需求
- 系统可用性：99.9%
- 数据准确性：确保计算结果的精确性

## 4. 用户场景

### 4.1 场景一：查看总持仓敞口
1. 用户登录系统
2. 导航至汇率管理->交易中心->仓位管理
3. 系统显示各币种对的敞口情况（折合USD）
4. 用户查看总持仓敞口数据

### 4.2 场景二：分析仓位分布
1. 用户进入仓位管理页面
2. 系统按敞口大小降序展示币种对
3. 用户查看各币种对的敞口金额和占比
4. 用户识别风险集中的币种对

### 4.3 场景三：设置最大敞口限制
1. 用户进入仓位管理页面
2. 点击设置按钮进入敞口限制设置
3. 输入单一货币对最大敞口限制值
4. 保存设置
5. 系统应用新的限制规则

## 5. 边界和范围定义

### 5.1 范围限定
- 仅处理外汇交易的仓位管理
- 不包括其他金融产品的仓位管理
- 仅支持USD作为基准货币进行折合计算

### 5.2 边界情况
- 无敞口的币种对不参与仓位分布分析
- 当卖出和买入金额相等时，敞口为0
- 当汇率异常波动时，系统应能正确处理折合计算

## 6. 验收标准

### 6.1 功能验收
- 总持仓敞口统计计算准确
- 仓位分布分析排序正确
- 最大敞口限制设置生效
- 菜单位置正确无误

### 6.2 性能验收
- 页面加载时间≤2秒
- 数据刷新延迟≤5秒

### 6.3 安全验收
- 未授权用户无法访问
- 数据传输加密验证通过

### 6.4 可靠性验收
- 系统稳定运行无异常
- 数据计算结果与预期一致
